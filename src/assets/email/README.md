# Email assets

Files here are **intentionally unreferenced by any page**. They are hosted only
so email clients can load them by URL — an image in a signature has to live at a
public address, or it travels as an attachment and gets stripped or flagged.

**Do not delete these as "unused".**

| file | served at | used for |
|---|---|---|
| `signature-2026.png` | `/assets/email/signature-2026.png` | the every\*one 2026 signature banner |
| `signature.png` | `/assets/email/signature.png` | the previous signature |

See `docs/email-signature.md` for the snippet to paste into Fastmail.
